CS 499 / ENHANCEMENT THREE

Database Enhancement.

Improving data integrity, query organization, and security within the AI Coloring Book Generator.

Artifact Overview

The AI Coloring Book Generator is an application that allows users to generate and save coloring book content.

The application maintains user accounts, coloring books, individual generated pages, and credit balances through a relational database implemented with SQLAlchemy.

I selected this artifact because database reliability is essential when an application stores user-generated content and manages credits associated with user accounts.

Original Database Limitations

The original application already used SQLAlchemy database models. However, several important rules were not enforced directly at the database level.

  • Negative credit balances were not prevented by database constraints.
  • Remaining credits could exceed the amount originally granted.
  • Invalid page counts could be stored.
  • Duplicate page numbers within the same coloring book were not prevented.
  • Some frequently used queries lacked matching composite indexes.
  • Book and image detail lookups checked ownership after retrieving records.

Enhancement 1: Data Integrity

I implemented database-level constraints to prevent invalid records from being stored in the application.

SQL CHECK constraints reject negative credits, remaining credits greater than the amount granted, invalid book page counts, and invalid individual page numbers.

A UNIQUE constraint also prevents two pages belonging to the same coloring book from sharing a page number.

Why This Matters

Database constraints protect data integrity even when application-level validation is incomplete or bypassed.

Enhancement 2: Database Indexing

I added composite indexes to support common database queries.

These indexes cover user books and images ordered by creation date, pages belonging to a book, and credit records organized by user and expiration date.

Why This Matters

Indexing can improve query performance by reducing unnecessary record scanning. Actual performance improvements would need to be measured using representative production-sized data.

Enhancement 3: Secure Data Access

I improved book and image detail queries by including the authenticated user's ID directly in the database lookup.

This means that the query retrieves only records belonging to the authenticated user.

Requests for records belonging to another user continue to receive a not-found response.

Why This Matters

User-scoped queries provide an additional layer of protection against unauthorized access to another user's saved content.

Automated Testing

I created six automated SQLite tests to verify the database enhancements.

  • Reject negative credit balances.
  • Reject excessive remaining credits.
  • Reject invalid book page counts.
  • Reject duplicate page numbers.
  • Verify user-scoped image access.
  • Verify index creation and initialization.

All six tests passed in the local environment during the milestone.

Testing Command

python -m unittest discover -s tests -p "test_database_enhancement.py" -v

Database Deployment Considerations

The new database constraints are applied when creating a fresh database.

Existing databases require a reviewed migration to check historical data and apply the necessary schema changes.

This distinction is important because successful testing with a new database does not demonstrate that an existing database has been migrated.

Reflection and Skills Demonstrated

This enhancement strengthened my ability to evaluate an existing database, identify potential integrity problems, and implement practical improvements.

I gained experience working with SQLAlchemy constraints, composite indexes, user-scoped queries, and automated database testing.

One important lesson was understanding that database security and integrity should not depend entirely on application-level logic.

I also learned that database schema changes require careful consideration of existing data and deployment procedures.

Course Outcomes

This enhancement demonstrates my ability to design and evaluate computing solutions, apply appropriate technical tools, communicate development decisions, and consider security during application development.

The database improvements support more reliable application behavior while strengthening the protection of user-generated content.
