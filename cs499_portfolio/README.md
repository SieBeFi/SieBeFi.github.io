# CS 499 Capstone ePortfolio starter

Open `index.html` in a browser (or with VS Code Live Server) to preview.

## Before submission
1. Replace all placeholder content with your final, accurate self-assessment and enhancement narratives.
2. Add a working code review video link.
3. Add original and enhanced code links (ideally distinct repository folders or commits).
4. Add your three Word narratives and self-assessment to `documents/` and link them.
5. Check every link, including the project repository URL, and test on desktop and mobile.

## Publish with GitHub Pages
Create a repository for this site, upload the files from this folder to its root, and commit. In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Wait for GitHub to display your published site URL.

This is a website starter, not a finished rubric-compliant submission until the actual artifacts and written work are included.
